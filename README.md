# MratuBhayas - Standalone Android Application

Complete Android native app matching 100% of the **MratuBhayas** ESP32 smart device functions:
- **Dhyan Engine**: Pranayama box breathing timer with acoustic tones & haptic feedback.
- **Niyam Engine**: Exact-second alarms powered by Android `AlarmManager.setAlarmClock()`, lock-screen full screen alert, auto-snooze, and daily missed/done audit logs.
- **Sanskar Engine**: Interval-based mindfulness chimes operating within customizable active hours.
- **Sadhana & Tracker**: Multi-sadhana challenges, live milestone countdowns, and dual completed/missed attendance tracking bars.
- **Planner Calendar**: Interactive monthly calendar with event scheduler.
- **Notes**: Digital notebook.
- **Nokia 8-Bit Tone Synthesizer**: Pure PCM acoustic sound engine playing all 15 authentic Nokia melodies without needing external audio files.

## How to Get the APK from GitHub (Cloud Build - No PC installation needed!)

1. **Create a new Repository on GitHub**:
   - Go to [github.com/new](https://github.com/new).
   - Name it `MratuBhayasApp` and click **Create repository**.
2. **Upload this folder**:
   - Click **"uploading an existing file"** on GitHub.
   - Drag and drop all the files from this `MratuBhayasApp` folder into GitHub and click **Commit changes**.
3. **Download your APK**:
   - As soon as you commit, click the **Actions** tab on your GitHub repository.
   - You will see the **"Build Android APK"** workflow running automatically.
   - Within 2-3 minutes, it completes! Click on the run and download **`MratuBhayas.apk`** from the **Artifacts** section directly to your phone.
